① ΔH < 0, ΔS > 0 ② ΔH < 0, ΔS < 0 ③ ΔH > 0, ΔS > 0 ④ ΔH > 0, ΔS < 0 ⑤ ΔH = 0, ΔS = 0

Ⅱ. 서술형 (7문항)

서술형 1. 산소 분자(O₂)의 분자 오비탈 이론에 대하여 다음 물음에 답하시오. [8점]
(1) O₂의 원자가 전자 총 개수를 쓰고, 원자가 전자의 분자 오비탈 전자 배치를 에너지 순서대로 쓰시오. [2점]
(2) O₂⁺의 결합 차수를 계산식과 함께 구하시오. [2점]
(3) O₂⁻(초과산화물 이온)의 상자성 여부를 판단하고 그 까닭을 설명하시오. [2점]
(4) O₂⁺, O₂, O₂⁻, O₂²⁻의 결합 길이를 짧은 것부터 순서대로 나열하고 근거를 쓰시오. [2점]
풀이 보기
(1) O 원자당 6개 → 총 12개. 배치: σ₂ₛ² σ*₂ₛ² σ₂ₚ² π₂ₚ⁴ π*₂ₚ².
(2) O₂⁺는 π* 전자가 1개 → 결합 차수 = (결합성 8 − 반결합성 3)/2 = 2.5.
(3) O₂⁻는 π* 오비탈에 전자 3개 → 홀전자 1개 존재 → 상자성. 홀전자가 있으면 자기장에 끌린다.
(4) 결합 차수: O₂⁺ 2.5 > O₂ 2 > O₂⁻ 1.5 > O₂²⁻ 1. 결합 차수가 클수록 결합이 강하고 짧으므로 O₂⁺ < O₂ < O₂⁻ < O₂²⁻.
서술형 2. 자료는 ₂₆Fe²⁺ 착이온의 색과 자기적 성질이다. 다음 물음에 답하시오. [8점]
[Fe(CN)₆]⁴⁻ : 노란색, 반자성
[Fe(H₂O)₆]²⁺ : 연한 녹색, 상자성
(분광학적 계열: CN⁻ > NH₃ > H₂O > F⁻)
(1) Fe²⁺의 d전자 개수를 쓰고, 두 착이온의 t₂g와 e_g 오비탈 전자 배치를 각각 나타내시오. [3점]
(2) [Fe(CN)₆]⁴⁻가 반자성이고 [Fe(H₂O)₆]²⁺가 상자성인 까닭을 결정장 갈라짐(Δ₀)과 강한 장·약한 장 개념으로 설명하시오. [3점]
(3) 두 착이온이 서로 다른 색을 띠는 까닭을 d–d 전이와 보색 관계로 설명하시오. [2점]
풀이 보기
(1) Fe: [Ar]3d⁶4s² → Fe²⁺는 d⁶. [Fe(CN)₆]⁴⁻: t₂g⁶ e_g⁰ (저스핀). [Fe(H₂O)₆]²⁺: t₂g⁴ e_g² (고스핀).
(2) CN⁻는 강한 장 리간드 → Δ₀가 짝지음 에너지보다 큼 → 전자 6개가 모두 t₂g에 짝지어 들어가 홀전자 0개 → 반자성. H₂O는 비교적 약한 장 → Δ₀가 작아 전자가 e_g까지 분산(훈트 규칙) → 홀전자 4개 → 상자성.
(3) Δ₀ 크기가 다르면 d–d 전이로 흡수하는 빛의 파장이 다르다. 흡수된 빛의 보색이 관찰되므로, Δ₀가 큰 [Fe(CN)₆]⁴⁻는 단파장(보라 부근)을 흡수해 노란색, Δ₀가 작은 [Fe(H₂O)₆]²⁺는 장파장(빨강 부근)을 흡수해 녹색 계열로 보인다.
서술형 3. 유효숫자 처리와 이상 기체 방정식에 대한 다음 물음에 답하시오. [6점]
(1) 측정값 45,000을 유효숫자가 3개임이 드러나도록 과학적 표기법으로 나타내시오. [2점]
(2) 127℃, 1.5 atm에서 어떤 이상 기체 8.2 L의 양(mol)을 풀이 과정과 함께 구하시오. (R = 0.082 atm·L/(K·mol)) [4점]
풀이 보기
(1) 4.50×10⁴ (4, 5, 0 세 자리가 유효함을 명시).
(2) T = 127 + 273 = 400 K. n = PV/RT = (1.5×8.2)/(0.082×400) = 12.3/32.8 = 0.375 mol (≒ 0.38 mol).
서술형 4. 자료는 이산화 질소의 이합체화 열화학 반응식이다. 다음 물음에 답하시오. [8점]
2NO₂(g) ⇌ N₂O₄(g) ΔH° = −57.2 kJ/mol
(298 K에서 평형 상수 K = 8.8, ln8.8 ≒ 2.2)
(1) 298 K에서 이 반응의 표준 자유 에너지 변화 ΔG°를 구하시오. (R = 8.314 J/(K·mol)) [3점]
(2) ΔG° = −RTlnK가 도출되는 과정을 ΔG = ΔG° + RTlnQ에서 출발하여 설명하시오. (평형 조건을 이용할 것) [2점]
(3) ΔS°가 온도에 따라 변하지 않는다고 가정할 때, (1)의 결과와 ΔH°를 이용하여 ΔS°를 구하시오. [3점]
풀이 보기
(1) ΔG° = −RTlnK = −8.314×298×2.2 ≒ −5,451 J/mol ≒ −5.5 kJ/mol.
(2) 평형에서는 ΔG = 0이고 Q = K이므로, 0 = ΔG° + RTlnK → ΔG° = −RTlnK.
(3) ΔG° = ΔH° − TΔS° → ΔS° = (ΔH° − ΔG°)/T = (−57.2 − (−5.5))/298 = −51.7/298 ≒ −0.173 kJ/(K·mol) = −173 J/(K·mol). (기체 분자 수가 2→1로 감소하므로 ΔS°<0은 타당)
서술형 5. 산–염기 평형에 대하여 다음 물음에 답하시오. [6점]
반응① CH₃COOH + NH₃ ⇌ CH₃COO⁻ + NH₄⁺
반응② HS⁻ + HF ⇌ H₂S + F⁻
(1) 두 반응에서 산, 염기, 짝산, 짝염기 쌍을 모두 작성하시오. [3점]
(2) 완충 용액에 소량의 산이나 염기를 넣어도 pH가 거의 변하지 않는 까닭을 설명하시오. [3점]
풀이 보기
(1) 반응①: 산 CH₃COOH ↔ 짝염기 CH₃COO⁻ / 염기 NH₃ ↔ 짝산 NH₄⁺.
반응②: 산 HF ↔ 짝염기 F⁻ / 염기 HS⁻ ↔ 짝산 H₂S.
(2) 완충 용액에는 약산(HA)과 그 짝염기(A⁻)가 함께 충분히 존재한다. 산(H⁺)을 넣으면 A⁻ + H⁺ → HA로, 염기(OH⁻)를 넣으면 HA + OH⁻ → A⁻ + H₂O로 소모되어 [H⁺]가 크게 변하지 않으므로 pH가 거의 일정하게 유지된다.
서술형 6. 자료는 Pb/Pb²⁺ 반쪽 전지와 Sn/Sn²⁺ 반쪽 전지로 구성한 볼타 전지에 대한 자료이다. 다음 물음에 답하시오. [8점]
Pb²⁺(aq) + 2e⁻ → Pb(s) E° = −0.13 V
Sn²⁺(aq) + 2e⁻ → Sn(s) E° = −0.14 V
네른스트 식: E전지 = E°전지 − (0.0592/n)logQ (25℃)
(단, log2 ≒ 0.30)
(1) 산화 전극과 환원 전극을 판별하고, 균형 잡힌 전체 반응식을 쓰고, E°전지를 구하시오. [3점]
(2) 초기 [Pb²⁺] = 0.40 M, [Sn²⁺] = 0.10 M일 때의 전지 전위 E전지를 구하시오. [4점]
(3) (2)의 E전지가 E°전지보다 큰(또는 작은) 까닭을 반응 지수 Q와 관련지어 설명하시오. [1점]
풀이 보기
(1) E°가 큰 Pb²⁺/Pb가 환원 전극, Sn/Sn²⁺이 산화 전극. 전체: Pb²⁺(aq) + Sn(s) → Pb(s) + Sn²⁺(aq). E°전지 = (−0.13) − (−0.14) = +0.01 V.
(2) Q = [Sn²⁺]/[Pb²⁺] = 0.10/0.40 = 1/4. logQ = −2log2 ≒ −0.60.
E = 0.01 − (0.0592/2)×(−0.60) = 0.01 + 0.01776 ≒ +0.028 V.
(3) Q < 1 (반응물 Pb²⁺ 농도가 생성물 Sn²⁺보다 큼) → 정반응 구동력이 표준 상태보다 크므로 E전지 > E°전지.
서술형 7. 세 가지 분자(이온)에 대하여 중심 원자의 혼성 오비탈을 쓰고, 분자(이온) 전체의 극성 여부를 각각 예측하시오. [6점/각 2점]
(1) PCl₃ (2) NH₄⁺ (3) CO₂
풀이 보기
(1) PCl₃: 결합 3 + 비공유 전자쌍 1 → sp³, 삼각뿔형 → 쌍극자 모멘트 상쇄 안 됨 → 극성.
(2) NH₄⁺: 결합 4 → sp³, 정사면체 대칭 → 상쇄 → 무극성(대칭 구조).
(3) CO₂: 결합 영역 2 → sp, 직선형 대칭 → 상쇄 → 무극성.

보강 1. 주 양자수 n=2, 부 양자수 l=1에 해당하는 오비탈의 개수로 옳은 것은?

정답 ②
보강 2. H₂O(끓는점 100℃)가 분자량이 더 큰 H₂S(끓는점 −60℃)보다 끓는점이 훨씬 높은 까닭을 분자 간 힘의 종류를 들어 설명하시오.
풀이 보기
H₂O는 전기 음성도가 큰 O에 결합한 H가 이웃 분자의 O 비공유 전자쌍과 수소 결합을 형성한다. 수소 결합은 분산력·쌍극자 힘보다 훨씬 강한 분자 간 인력이므로, 분자량이 작아도 H₂S(수소 결합 없음, 분산력 위주)보다 끓는점이 크게 높다.
보강 3. 25℃에서 0.0010 M HCl 수용액의 pH로 옳은 것은? (HCl은 완전히 이온화한다고 가정)
① 1② 2③ 3④ 4⑤ 11
풀이 보기
[H⁺] = 1.0×10⁻³ M → pH = −log(10⁻³) = 3.
